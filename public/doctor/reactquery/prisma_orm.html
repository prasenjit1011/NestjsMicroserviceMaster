# Basic Query Methods

| Keyword          | Purpose               |
| ---------------- | --------------------- |
| `findMany()`     | Get multiple rows     |
| `findUnique()`   | Get single unique row |
| `findFirst()`    | First matching row    |
| `create()`       | Insert row            |
| `createMany()`   | Insert multiple       |
| `update()`       | Update single         |
| `updateMany()`   | Update many           |
| `delete()`       | Delete single         |
| `deleteMany()`   | Delete many           |
| `upsert()`       | Update or insert      |
| `count()`        | Count rows            |
| `aggregate()`    | AVG/SUM/MIN/MAX       |
| `groupBy()`      | SQL GROUP BY          |
| `$transaction()` | Transaction           |
| `$queryRaw()`    | Raw SQL               |

# Relation Keywords

Prisma DOES NOT use:

* `belongsTo`
* `hasMany`
* `hasOne`

Like Sequelize.

Instead Prisma uses:

* relation fields
* `@relation`

---

# One-to-Many Relation

```prisma id="jlf9mq"
model User {
  id    Int    @id @default(autoincrement())
  posts Post[]
}

model Post {
  id      Int  @id @default(autoincrement())
  userId  Int
  user    User @relation(fields: [userId], references: [id])
}
```

Equivalent meaning:

| Sequelize | Prisma              |
| --------- | ------------------- |
| hasMany   | posts Post[]        |
| belongsTo | user User @relation |

# connectOrCreate

```ts id="wlqkq4"

    title: "Hello",
```
