  • What is Spring Boot?
    Spring Boot is a framework built on top of Spring that simplifies the development of stand-alone, production-ready Spring-based applications with minimal configuration.
  • What are the main features of Spring Boot?
    Auto-configuration, starter dependencies, embedded servers, production-ready metrics, and minimal XML configuration.
  • What is the difference between Spring and Spring Boot?
    Spring provides a comprehensive framework for Java development, while Spring Boot simplifies the setup and development process with auto-configuration and embedded servers.
  • What is a Spring Boot Starter?
    Starters are a set of convenient dependency descriptors you can include in your application to get common functionality, like spring-boot-starter-web for web apps.
  • How does Spring Boot reduce boilerplate code?
    Through auto-configuration, embedded servers, and opinionated defaults for project structure and dependencies.
  • What is @SpringBootApplication?
    A convenience annotation that combines @Configuration, @EnableAutoConfiguration, and @ComponentScan.
  • How do you create a Spring Boot project?
    Use Spring Initializr (https://start.spring.io) or IDEs like IntelliJ or Eclipse with Spring support.
  • What is auto-configuration in Spring Boot?
    Spring Boot automatically configures your application based on the dependencies present in the classpath.
  • What is the purpose of application.properties?
    It is used to define configuration values such as server port, datasource URL, and logging level.
  • What is an embedded server?
    Spring Boot includes servers like Tomcat, Jetty, or Undertow within the application, so you don’t need to deploy a WAR file externally.
  • What is dependency injection?
    A design pattern where dependencies are provided to a class by the framework instead of being created manually.
  • What is @RestController?
    A combination of @Controller and @ResponseBody, used to build RESTful web services in Spring Boot.
  • What is the difference between @Component, @Service, and @Repository?
    All are specializations of @Component used for different layers: general bean, business logic, and data access respectively.
  • How do you handle exceptions in Spring Boot?
    Use @ControllerAdvice with @ExceptionHandler methods to define global exception handling logic.
  • What is Spring Boot DevTools?
    A module that provides automatic restarts, live reload, and configurations for faster development.
  • What is @Autowired?
    It tells Spring to automatically inject the required bean into a component.
  • How can you change the default port in Spring Boot?
    Add server.port=8081 in application.properties or application.yml.
  • What is Spring Boot Actuator?
    A tool that provides production-ready features like monitoring, health checks, metrics, and environment info.
  • How do you connect to a database in Spring Boot?
    Add spring-boot-starter-data-jpa and database driver dependencies, and configure the datasource in application.properties.
  • What is JPA in Spring Boot?
    Java Persistence API (JPA) is used for ORM-based database operations, often with Hibernate as the implementation.
  • What is @Entity?
    Marks a class as a JPA entity that maps to a table in the database.
  • What is a repository in Spring Boot?
    An interface extending JpaRepository or CrudRepository that provides CRUD operations without writing SQL.
  • What is H2 Database?
    An in-memory database useful for development and testing in Spring Boot projects.
  • What is the purpose of @RequestMapping?
    It maps HTTP requests to handler methods in controllers. You can also use shortcuts like @GetMapping, @PostMapping, etc.
  • What is a DTO?
    Data Transfer Object is used to carry data between layers, typically between controller and service.
  • What is @PathVariable?
    Used to extract values from the URI in controller methods.
  • What is @RequestParam?
    Used to extract query parameters from the URL in controller methods.
  • How do you secure a Spring Boot app?
    Use Spring Security with configurations for authentication, authorization, and password encoding.
  • How can you schedule tasks in Spring Boot?
    Use @EnableScheduling and annotate methods with @Scheduled for cron jobs or fixed intervals.
  • What are common Spring Boot dependencies?
    spring-boot-starter-web, spring-boot-starter-data-jpa, spring-boot-starter-security, spring-boot-devtools, spring-boot-starter-actuator.

    package com.example.employee.repository;

    import com.example.employee.model.Employee;
    import org.springframework.data.jpa.repository.JpaRepository;
    
    public interface EmployeeRepository extends JpaRepository {}
    

    

    package com.example.employee.service;

    import com.example.employee.model.Employee;
    import com.example.employee.repository.EmployeeRepository;
    import org.springframework.beans.factory.annotation.Autowired;
    import org.springframework.stereotype.Service;
    
    import java.util.List;
    
    @Service
    public class EmployeeService {
    
        @Autowired
        private EmployeeRepository employeeRepository;
    
        public List getAllEmployees() {
            return employeeRepository.findAll();
        }
    
        public Employee getEmployeeById(Long id) {
            return employeeRepository.findById(id).orElse(null);
        }
    
        public Employee createEmployee(Employee employee) {
            return employeeRepository.save(employee);
        }
    
        public Employee updateEmployee(Long id, Employee employeeData) {
            Employee employee = employeeRepository.findById(id).orElse(null);
            if (employee != null) {
                employee.setName(employeeData.getName());
                employee.setRole(employeeData.getRole());
                employee.setEmail(employeeData.getEmail());
                return employeeRepository.save(employee);
            }
            return null;
        }
    
        public void deleteEmployee(Long id) {
            employeeRepository.deleteById(id);
        }
    }
    

    
    package com.example.employee.controller;

    import com.example.employee.model.Employee;
    import com.example.employee.service.EmployeeService;
    import org.springframework.beans.factory.annotation.Autowired;
    import org.springframework.web.bind.annotation.*;
    
    import java.util.List;
    
    @RestController
    @RequestMapping("/api/employees")
    public class EmployeeController {
    
        @Autowired
        private EmployeeService employeeService;
    
        @GetMapping
        public List getAllEmployees() {
            return employeeService.getAllEmployees();
        }
    
        @GetMapping("/{id}")
        public Employee getEmployeeById(@PathVariable Long id) {
            return employeeService.getEmployeeById(id);
        }
    
        @PostMapping
        public Employee createEmployee(@RequestBody Employee employee) {
            return employeeService.createEmployee(employee);
        }
    
        @PutMapping("/{id}")
        public Employee updateEmployee(@PathVariable Long id, @RequestBody Employee employeeData) {
            return employeeService.updateEmployee(id, employeeData);
        }
    
        @DeleteMapping("/{id}")
        public void deleteEmployee(@PathVariable Long id) {
            employeeService.deleteEmployee(id);
        }
    }

  • Spring Boot Example : Encapsulation, Inheritance, Polymorphism, Abstraction 
    



// Abstraction
abstract class Payment {
    protected double amount;

    // Encapsulation (private data with getter/setter)
    public void setAmount(double amount) {
        this.amount = amount;
    }

    public double getAmount() {
        return amount;
    }

    // Abstract method (must be implemented by child)
    abstract void pay();
}

// Inheritance
class CreditCardPayment extends Payment {

    // Polymorphism (method overriding)
    @Override
    void pay() {
        System.out.println("Paid " + amount + " using Credit Card");
    }
}

class UpiPayment extends Payment {

    // Polymorphism (method overriding)
    @Override
    void pay() {
        System.out.println("Paid " + amount + " using UPI");
    }
}

// Spring Boot Main Application
import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class DemoApplication {

    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args);

        // Polymorphism (same reference, different behavior)
        Payment payment1 = new CreditCardPayment();
        payment1.setAmount(1000);
        payment1.pay();

        Payment payment2 = new UpiPayment();
        payment2.setAmount(500);
        payment2.pay();
    }
}
  • Spring Boot Example : Collections (List, Set, Map, HashMap) 
    
import java.util.*;

public class CollectionExample {

    public static void main(String[] args) {

        // ===== LIST =====
        List list = new ArrayList<>();
        list.add("Java");
        list.add("Spring");
        list.add("Java");

        System.out.println("List: " + list);
        // Output: List: [Java, Spring, Java]


        // ===== SET =====
        Set set = new HashSet<>();
        set.add("Java");
        set.add("Spring");
        set.add("Java");

        System.out.println("Set: " + set);
        // Output: Set: [Java, Spring]  (order may vary)


        // ===== MAP =====
        Map map = new HashMap<>();
        map.put(1, "Java");
        map.put(2, "Spring");
        map.put(1, "Updated Java");

        System.out.println("Map: " + map);
        // Output: Map: {1=Updated Java, 2=Spring}


        // ===== HASHMAP =====
        HashMap hashMap = new HashMap<>();

        hashMap.put("A", 1);
        hashMap.put("B", 2);
        hashMap.put("C", 3);
        hashMap.put("Aa", 100);
        hashMap.put("BB", 200);

        System.out.println("HashMap: " + hashMap);
        // Output: HashMap: {A=1, B=2, C=3, Aa=100, BB=200}
        // (order may vary)

        System.out.println("Get A: " + hashMap.get("A"));
        // Output: Get A: 1


        for (Map.Entry entry : hashMap.entrySet()) {
            System.out.println(entry.getKey() + " -> " + entry.getValue());
            // Output:
            // A -> 1
            // B -> 2
            // C -> 3
            // Aa -> 100
            // BB -> 200
            // (order may vary)
        }
    }
}

  • Multithreading & Concurrency in Java: A Simple Example

    Multithreading = Multiple threads inside a single program running simultaneously.

    
class MyThread extends Thread {
    public void run() {
        System.out.println("Thread is running: " + Thread.currentThread().getName());
    }
}

public class Main {
    public static void main(String[] args) {
        MyThread t1 = new MyThread();
        MyThread t2 = new MyThread();

        t1.start(); // starts thread 1
        t2.start(); // starts thread 2

        System.out.println("Main thread finished");
    }
